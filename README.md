# Airbnb Price Recommendation System

## Overview
The **Airbnb Price Recommendation System** is a machine learning project designed to predict optimal pricing for **Airbnb listings of Newyork City** based on various features such as location, property type, amenities, and more. This system helps hosts maximize their revenue while staying competitive in the market.

## Features
- Data preprocessing and feature engineering.
- Machine learning models for price prediction.
- Evaluation metrics to assess model performance.
- Streamlit app to predict the price per day based on features

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/ShrijithSM/Airbnb-Price-Recommendation-System.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Airbnb-Price-Recommendation-System
    ```
3. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```
